# Nephele Sound

**为 Linux 桌面做原生、安静、好看的音乐软件**

*Native, quiet and beautiful music software for the Linux desktop.*

</div>

Nephele（涅斐勒）是希腊神话里由云化成的仙女。我们相信听歌这件事值得一个和桌面融为一体的工具：原生渲染、跟随系统、不打扰你。

## 我们在意的

- **原生**：用桌面自己的工具包和组件，跟随系统的配色、字体、图标与动画速度。
- **安静**：排版先行，装饰只在有用的地方出现。
- **自由**：以 GPL 发布，欢迎 Issue 与 Pull Request。
